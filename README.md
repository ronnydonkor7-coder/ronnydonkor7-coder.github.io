# Ronny Donkor — Still Becoming

Edition 1 of my personal storytelling website: learning, curiosity, systems and the future taking shape.

Static HTML/CSS/JavaScript. All three images are embedded in `index.html`; there are no build dependencies or separate image folders.

## Run locally
Open `index.html` in a modern browser, or run `python3 -m http.server 8080` and visit http://localhost:8080.

## Hosting
Published with GitHub Pages from the main branch/root. No real payment flow, tracking analytics or contact backend is included. The contact link opens an email application.

The study room and other visual scenes are artistic illustrations rather than documentary evidence of biographical events. Projects retain their stated development status.
