CYBERSECURITY / HOME LAB

SENTINEL-X

A Raspberry Pi intrusion-detection lab that turns Suricata network events into a dashboard I can investigate.

← All projects

From packets to an alert

I wanted to follow a detection all the way through: generate test traffic, find the matching event in Suricata’s logs, and see it appear in a browser. I configured Suricata on my Raspberry Pi 5 and connected a Python/Flask dashboard to its EVE JSON log.

What is working

Suricata writes network events to /var/log/suricata/eve.json. The Flask application reads a recent event window and displays event, alert and flow counts. The dashboard includes severity totals and a table with timestamps, source and destination addresses, and detection names.

How I tested it

I used ICMP traffic in my own lab to trigger a rule named SENTINEL-X ICMP Test Alert. I checked the alert in the EVE log and then confirmed that it appeared in the dashboard. The captured result shows four low-severity test alerts. An ICMP test proves the detection path works; it does not establish that an attack occurred.

Tools and access

Raspberry Pi 5, Raspberry Pi OS, Suricata, Python, Flask, JSON, HTML and JavaScript. I use SSH from my Windows 11 laptop and access the local dashboard through an SSH tunnel.

Troubleshooting

The build involved checking the Suricata service and log output, working through log permissions, and testing the connection between the Flask endpoint and the browser. Keeping the raw log and dashboard open together helped me trace where data stopped moving.

What I learned

A counter alone is not enough. I need the rule name, time and network addresses to understand what triggered a detection. I also need to know which events the dashboard has loaded: a 500-event window is not a lifetime total.

Next steps

I’m continuing to check alert filtering and dashboard refresh behavior, then documenting more controlled detection tests. Wazuh integration and AI-assisted analysis are planned. They are not part of the verified working setup yet.

Earlier lab work

The repository also contains a Python detector for synthetic login events and a default-deny network policy model. Those remain separate exercises; packet-level segmentation validation is still planned.

Current stage: working Suricata detection and local dashboard; development continues. Project source and progress notes are maintained in my private cybersecurity home-lab repository.
